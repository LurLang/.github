# LurLang

**A native programming language and runtime designed for applications, games, embedded systems and operating systems.**

LurLang is designed to provide a lightweight runtime with native performance and the flexibility to run across different environments.

## Ecosystem

* **LurLang** — language and compiler
* **Runtime** — execution environment and VM
* **Standard Library** — core APIs and utilities
* **Tooling** — development and build tools
* **LurOS Integration** — native system and application development

## Designed for

* 🖥️ Desktop applications
* 🎮 Games
* 📺 TV applications
* 📱 Mobile applications
* 🔌 Embedded software
* ⚙️ System components
* 🐧 LurOS

LurLang is designed to remain useful independently of LurOS. It can be embedded into other software and used for projects ranging from applications and games to constrained embedded environments.

## Development

LurLang is developed as an independent open-source project and serves as the native language/runtime of the Lur ecosystem.
